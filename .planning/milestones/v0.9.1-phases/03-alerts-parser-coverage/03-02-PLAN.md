<objective>
Prove the two XML regional parsers (MeteoAlarm, ECCC) and the offline-provable region
routing, then verify `src/alerts.rs` clears the >= 65% line-coverage bar. Both parsers are
already standalone sync functions (`parse_meteoalarm_entry`, `parse_eccc_cap`) so they need
no extraction — only fixtures and assertions. This plan is additive test code except for one
conditional contingency extraction used only if the coverage number falls short.

Purpose: MeteoAlarm and ECCC carry the file's trickiest decode paths — CAP-namespace XML,
polygon containment, offset-form timestamps, and a shared mutable dedup set. Each has a
documented landmine (RESEARCH Pitfalls 1, 4, 5) that a naive fixture would silently pass for
the wrong reason. This plan tests them deliberately, then measures coverage and closes any
gap with the pre-scoped ECCC HTML-scraping extraction.

Per REVIEWS.md (Codex, incorporated):
- **Finding 2:** the language "dispatch proven" is downgraded throughout to "routing proven;
  live dispatch arms are an accepted, documented gap" — offline tests can only prove the
  `Region::Unknown => Ok(vec![])` arm plus the `detect_region` routing decision, not the
  US/Europe/Canada/Australia arms that invoke live HTTP.
- **Finding 3:** Task 1 now has an explicit acceptance criterion that the observed working
  MeteoAlarm namespace binding form (prefixed `cap:*` vs unprefixed) is recorded verbatim
  in the SUMMARY, and MeteoAlarm test assertions are tied to the observed form — no more
  fixture-trap risk of passing for the wrong reason.
- **Finding 1:** Task 3 now measures coverage TWICE in this wave — once after
  MeteoAlarm+ECCC tests (mid-Wave-2, before the dispatch task) using Plan 01's recorded
  llvm-cov invocation, and once at the end. The mid-Wave-2 read lets the executor apply
  the ECCC-listing contingency deliberately rather than as an end-of-phase scramble.

Output: MeteoAlarm/ECCC/routing tests, a confirmed `alerts.rs` coverage number >= 65%
with mid-Wave-2 + final measurements both recorded in the SUMMARY, the observed
MeteoAlarm namespace form recorded, and the four success criteria for COV-01 fully proven
(with the accepted live-arm gap explicitly documented). Wire contract stays byte-identical.
</objective>
