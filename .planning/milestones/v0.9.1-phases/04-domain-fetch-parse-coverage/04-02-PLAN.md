<objective>
Make the headline-AQI resolution decision (US EPA scale vs European scale vs AQICN
override, plus the Open-Meteo-default fallback when a scale value is missing) testable via
a mechanical sync-helper extraction, then prove the AQI parse, the optional AQICN headline
merge, and the AqiSource tracking with fixture-based `#[test]` functions.

Purpose: `src/air_quality.rs` is currently near-zero covered because the ternary
decision at lines 185-211 (which selects `(aqi, category, aqi_source)` from three possible
sources) is trapped inside `async fn fetch_air_quality` alongside live HTTP and the
`fetch_headline_aqi` await. This plan pulls that decision into a sync helper with no
behavior change and covers COV-03's three named surfaces: "AQI parse", "optional AQICN
headline merge", and "AqiSource tracking".

The existing #[cfg(test)] mod tests block at line 242 already has one test
(`aqi_source_defaults_to_open_meteo`) — new tests extend it in place (no new module,
no relocation).

Per Phase 3's proven method: baseline + post-plan `cargo llvm-cov` measurements are
recorded in the SUMMARY so the module-target improvement is a measured delta.

Output: one private sync helper, an extended `#[cfg(test)] mod tests` block with roughly
15-18 fixture-based tests (6 resolve_headline_aqi branches + 6 US-category boundaries +
6 EU-category boundaries + 2 AirQualityData::standard() cases + 1 pollutant-defaults
case), and two measured llvm-cov numbers in the SUMMARY. Wire contract stays byte-identical.
</objective>
