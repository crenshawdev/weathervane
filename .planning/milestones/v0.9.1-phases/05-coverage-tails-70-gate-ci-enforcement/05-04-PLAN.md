<objective>
Close the deterministically-testable portion of the `src/weather_jma.rs` tail
(baseline 71.95%, 69 uncovered lines per 05-CONTEXT.md) by extracting the map-lookup +
MAX_HOPS + temp-flag validation loop from `override_current_temp` (lines 72-83) into
a new private sync fn `select_temp_from_map`, then covering that fn's decision arms
against fixture HashMaps. Also add a targeted test for the one uncovered arm of
`parse_station_entry` (elems[0] != '1' non-temperature-station drop).

Purpose: `src/weather_jma.rs` is the third-widest tail (69 uncovered lines), but most
of those lines are inside async fns that call `crate::client::{get_json, get_text}`
against live JMA endpoints (override_current_temp, cached_stations, fetch_stations,
latest_observation_time, fetch_map). Per D-06/D-07, tests target parse/logic helpers,
not live HTTP. This plan mirrors the proven Phase 3/4 sync-helper extraction pattern
(nws_alerts_from_response, resolve_current_temp): pull the decision logic out of the
async wrapper into a pure sync fn that can be unit tested against fixture HashMaps.
The extraction is mechanical — same MAX_HOPS window, same temp[1] == 0.0 validity flag,
same to_unit conversion, same tracing::debug! log for the no-valid-temp path.

The elems[0] != '1' arm of parse_station_entry silently drops non-temperature-capable
AMeDAS stations (per the doc comment at src/weather_jma.rs:126-129, "Non-temp stations
are dropped silently"). The existing tests use elems="10000000" so they never trigger
this arm; the new test uses elems="00000000" to prove the silent-drop behavior.

Per Phase 3/4 proven method: baseline + post-plan `cargo llvm-cov` measurements are
recorded in the SUMMARY so the tail lift is a measured delta and Plan 05-05 (COV-07
workspace verification) has a real per-module datum.

Output: one new private sync helper (~10 lines, exact cut-and-relocate of the loop),
one extended `#[cfg(test)] mod tests` block with ~6-7 new tests, and two measured
llvm-cov numbers in the SUMMARY. Wire contract stays byte-identical.
</objective>
