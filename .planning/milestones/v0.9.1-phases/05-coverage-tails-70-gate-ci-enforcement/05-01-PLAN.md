<objective>
Close the remaining line-coverage tail on `src/codes.rs` (baseline 62.37%, 35 uncovered
lines per 05-CONTEXT.md) by adding fixture-based unit tests for every currently-uncovered
match arm across the file's three surface areas: `WeatherCondition::from_code` (the WMO
code table), `WeatherCondition::icon_name` (the freedesktop icon-name mapper, currently
0% covered), and `CompassDirection::as_str` (the compass-label mapper, currently 0%
covered), plus interior-arc coverage for `CompassDirection::from_degrees`.

Purpose: `src/codes.rs` is currently the widest single-module gap for this phase
(62.37% baseline, ~35 uncovered lines). Every uncovered line is inside a pure `match`
arm on a small enum — the cheapest and highest-yield tail-lift target in Phase 5
(05-CONTEXT.md §Specifics: "cheapest lift; start there"). No source extraction is
needed — every arm is already reachable from the existing `#[cfg(test)] mod tests`
block via `use super::*`. This plan is pure test addition.

Per Phase 3/4 proven method (03-01-SUMMARY.md, 04-*-SUMMARY.md): baseline + post-plan
`cargo llvm-cov` measurements are recorded in the SUMMARY so the tail lift is a measured
delta rather than an assumption, and Plan 05-05 (COV-07 verification) has a real
per-module datum to feed into the workspace ≥75% CI gate decision.

Style note (per REVIEWS.md Codex/Gemini divergence): tests in Group B are per-arm
(one test per icon_name match arm) rather than table-driven. Codex suggested table
form to reduce line count; Gemini praised exhaustive per-arm layout for readability
and one-arm-per-diagnosis blast radius. Per-arm is chosen because (a) a broken icon
name string that ships would surface as a specific named test failure (e.g.
`icon_name_thunderstorm_family_shares_symbol` immediately identifies the affected
arm), (b) each arm's test can be run in isolation via `cargo test --lib
codes::tests::icon_name_<name>` for triage, and (c) the total line count is small
enough that boilerplate cost is negligible. This is style, not correctness.

Output: one extended `#[cfg(test)] mod tests` block at the bottom of `src/codes.rs`
with roughly 18-22 new tests, and two measured llvm-cov numbers (baseline + post-plan)
in the SUMMARY. Wire contract stays byte-identical.
</objective>
