## Phase Details

### Phase 3: Alerts Parser Coverage

**Goal**: `alerts.rs` — the single largest coverage gap (394 uncovered lines, 0% baseline) — is exercised end to end across all four regional parsers and the dispatch/expiry logic, entirely against extracted helpers and fixtures (no live HTTP).
**Depends on**: Nothing (first phase of this milestone; builds on shipped v0.9)
**Requirements**: COV-01
**Success Criteria** (what must be TRUE):

  1. All four regional alert parsers (NWS JSON, MeteoAlarm XML, ECCC, BOM) decode representative fixtures into `Alert` values with expected fields, proven by tests.
  2. The expired-alert filter is proven by tests: alerts past their expiry are dropped and current ones retained.
  3. Region dispatch is proven by tests: coordinates in each supported region select the correct provider parser path.
  4. `cargo test --workspace` is green and the wire contract (`tests/wire_contract.rs` + `tests/snapshots/`) is unchanged.
  5. `alerts.rs` line coverage rises from 0% to a substantial majority of its lines, measured via `cargo llvm-cov`.

**Plans**: 2 plans
**Wave 1**

- [x] 03-01-PLAN.md — Sync-helper extractions (NWS/BOM/MeteoAlarm-feed) + NWS/BOM JSON parser tests + from_cap_string

**Wave 2** *(blocked on Wave 1 completion)*

- [x] 03-02-PLAN.md — MeteoAlarm/ECCC XML parser tests, region dispatch, and ≥65% coverage verification

### Phase 4: Domain Fetch/Parse Coverage

**Depends on**: Phase 3
**Requirements**: COV-02, COV-03, COV-04, COV-05
**Success Criteria** (what must be TRUE):

  1. `weather.rs` Open-Meteo response → `WeatherData` parse and the JMA current-temp override path are covered by tests.

  5. `cargo test --workspace` is green and the wire contract (`tests/wire_contract.rs` + `tests/snapshots/`) is unchanged.

### Phase 5: Coverage Tails, ≥70% Gate & CI Enforcement

**Goal**: Fill the remaining coverage tails to cross the ≥70% workspace bar, verify it, and lock it in with a failing CI threshold so coverage cannot silently regress. This is the milestone-completion gate — the CI gate is added only after ≥70% is verified.
**Depends on**: Phase 4
**Requirements**: COV-06, COV-07, COV-08
**Success Criteria** (what must be TRUE):

  1. Coverage tails on `geo.rs`, `time.rs`, `weather_jma.rs`, and `codes.rs` are raised toward their module targets via new tests.
  2. `cargo llvm-cov --workspace` reports workspace line coverage ≥70%.
  3. The GitLab `coverage` job in `.gitlab-ci.yml` fails the pipeline when line coverage drops below the enforced threshold (via `cargo llvm-cov --fail-under-lines`), added after ≥70% is reached.
  4. `cargo test --workspace` is green and the wire contract (`tests/wire_contract.rs` + `tests/snapshots/`) is unchanged.
